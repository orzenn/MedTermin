# МедТермин · Streamlit

Учебный мультиагентный справочник медицинских понятий на основе MeSH и MedlinePlus.

## Локальный запуск

```sh
python -m venv .venv
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Перед установкой зависимостей активируйте созданное окружение либо вызывайте его интерпретатор напрямую.

## Что реализовано

Планировщик → агент MeSH → агент MedlinePlus → агент объяснения → агент проверки. Есть выбор понятия при неоднозначности, ссылки и даты источников, показ оригинального текста, времён обработки и скачивание справок.

Локальная официальная выгрузка MedlinePlus от 11.11.2026 содержит 1017 англоязычных тем. Шесть подготовленных русских примеров и записи MeSH доступны без сети. В ответах явно различаются текущие данные и сохранённые материалы. Онлайн-поиск и перевод могут быть недоступны из-за ограничений внешних сервисов.

В этой версии программные агенты работают по заданным правилам. Генеративная языковая модель не подключена. Для новых русских запросов и перевода фрагментов используется внешний сервис MyMemory. Не вводите персональные медицинские данные.

Сохранённые справки хранятся в текущем сеансе Streamlit; их можно скачать. Ссылки и структурные проверки не заменяют медицинскую экспертизу.

```sh
python -m unittest discover -s tests_python -v
```

Источник справочных материалов: MedlinePlus, National Library of Medicine. Русские объяснения не являются официальным переводом NLM. Приложение не устанавливает диагнозы и не даёт индивидуальных назначений.
