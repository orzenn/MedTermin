# МедТермин · практическая работа №2

Учебный мультиагентный справочник на основе MeSH и MedlinePlus с разделом «Инструменты MCP». Исходная версия справочника: [`2cd5eb0`](https://github.com/orzenn/MedTermin/commit/2cd5eb0).

## Локальный запуск

Требуется Python 3.11 или 3.12. Один раз создайте окружение и установите зависимости (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --index-url https://pypi.org/simple -r requirements.txt
```

Запускайте веб-приложение и локальный сетевой сервер одной командой:

```powershell
.\.venv\Scripts\python.exe -m medterm_mcp.launch
```

Откройте `http://127.0.0.1:8511`. В Linux или macOS замените `.\.venv\Scripts\python.exe` на `./.venv/bin/python`. Если порт занят, передайте `--web-port 8512` или `--mcp-port 8001`. Остановить оба процесса можно через Ctrl+C.

## Три подключения MCP

| Источник | Что доступно | Как устроено |
| --- | --- | --- |
| Локальный stdio | ИМТ, площадь поверхности тела, шкала комы Глазго, `list_calculators` | Клиент запускает `python -m medterm_mcp.server` как дочерний процесс. `stdout` предназначен для JSON-RPC; журнал идёт в `stderr`. Каналы и процесс закрывает SDK. |
| Локальный SSE | Те же три расчёта, среднее АД, шоковый индекс и каталог | Независимый процесс слушает `127.0.0.1:8000`. `/sse` принимает подписку; POST отправляется на выданный сервером `/messages/?session_id=…`. Клиент повторяет подключение при кратком отказе порта, до отправки расчёта. |
| Внешний PubMed | Поиск публикаций по теме с переходом к библиографической записи | [PubMed MCP из Glama](https://glama.ai/mcp/servers/eLambert2560/pubmed-mcp-server), публичный [сервер проекта cyanheads](https://github.com/cyanheads/pubmed-mcp-server#overview). Клиент вызывает `pubmed_search_articles` по HTTPS / Streamable HTTP. Нет ключа. Бюджет одного сетевого обмена — 12 секунд; успешные ответы кешируются до 15 минут (до 64 записей). |

Оба локальных сервера используют официальный Python SDK `mcp==2.3.0`. Клиент явно выполняет `initialize` и `notifications/initialized` для совместимости с заданным в работе обменом. Список инструментов запрашивается через `tools/list`, результат — через `tools/call`. При смене инструмента форма строится из входной JSON Schema, полученной от сервера. Инспектор показывает перехваченные JSON-RPC сообщения с идентификаторами запросов и ответов. Методы и формулы запускаются только на MCP-серверах. Модель для расчётов и маршрутизации не нужна.

Санитайзер приводит числа к нужному типу и заполняет безопасные необязательные параметры (например, пять статей). Поля с измерениями и баллами изначально пустые: значения подставляются только кнопкой «Подставить учебный пример». Границы и отношения полей валидируются на сервере; ошибки вывода отображаются как предупреждения с ответом MCP. Это учебные формы: не вводите персональные медицинские данные и не используйте результаты для назначений.

Конфигурация IDE: `.cursor/mcp.json`. Для `stdio` IDE должна запускать `python` из окружения проекта с установленными зависимостями (при необходимости укажите полный путь к интерпретатору). Для SSE запустите `python -m medterm_mcp.server --transport sse`. Для внешнего подключения локальный запуск не нужен.

## Сценарий защиты

1. В меню выберите «Инструменты MCP» → «Локальный stdio» → «Индекс массы тела». Подставьте учебный пример и вызовите инструмент. Получится около 22,86 кг/м². Раскройте инспектор и покажите `initialize`, `tools/call` и ответ с тем же `id`.
2. Переключитесь на «Локальный SSE» → «Среднее артериальное давление». Для учебных 120/78 результат — 92 мм рт. ст. Введите систолическое АД ниже диастолического и покажите предупреждение вместо падения приложения.
3. Переключитесь на «Внешний PubMed». Подставьте пример про систематические обзоры по астме и нажмите «Искать публикации». Покажите список, ссылку на статью и JSON-RPC. Повторите тот же запрос: кеш отдаёт ранее полученный ответ. Для этой части нужен Интернет.

Короткие ответы на вопросы преподавателя — в [защите](DEFENSE.md).

## Что реализовано

Планировщик → агент MeSH → агент MedlinePlus → агент объяснения → агент проверки. Есть выбор понятия при неоднозначности, ссылки и даты источников, показ оригинального текста, времён обработки и скачивание справок.

Локальная официальная выгрузка MedlinePlus от 11.11.2026 содержит 1017 англоязычных тем. Шесть подготовленных русских примеров и записи MeSH доступны без сети. В ответах явно различаются текущие данные и сохранённые материалы. Онлайн-поиск и перевод могут быть недоступны из-за ограничений внешних сервисов.

В этой версии программные агенты работают по заданным правилам. Генеративная языковая модель не подключена. Для новых русских запросов и перевода фрагментов используется внешний сервис MyMemory. Не вводите персональные медицинские данные.

Варианты перевода запросов сверяются со словарём источника. Неоднозначные переводы и похожие названия предлагаются пользователю на выбор, а не исправляются автоматически. При переводе справок сохраняются пары «оригинал — перевод» и проверяются числа; при расхождении отображается оригинал. Успешные переводы публичных фрагментов кешируются в памяти на срок до 24 часов (до 256 фрагментов). Эти проверки не гарантируют правильность медицинского смысла.

Сохранённые справки хранятся в текущем сеансе Streamlit; их можно скачать. Ссылки и структурные проверки не заменяют медицинскую экспертизу.

## Проверки

```sh
python -m unittest discover -s tests_python -v
```

Сетевой тест подключается к временному порту на loopback. Для проверки внешнего PubMed выполните `python -m medterm_mcp.smoke_pubmed` (нужен Интернет).
